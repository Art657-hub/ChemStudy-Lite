# ChemStudy Lite

Облегчённая автономная версия ChemStudy на HTML5, CSS3 и Vanilla JavaScript. Приложение не использует backend, Node.js, Python, npm, внешние API и ИИ-ключи. Все данные сохраняются в IndexedDB текущего браузера и не синхронизируются между устройствами.

## Запуск

1. Распакуйте папку `ChemStudy-Lite` целиком.
2. Откройте `index.html` актуальным Chrome, Edge или Firefox. Сборка и установка зависимостей не нужны.
3. Если браузер ограничивает IndexedDB на `file://`, запустите файл через локальный статический HTTP-сервер, например расширение Live Server в редакторе. Это только раздача файлов, приложение не требует backend.

## Структура и миграции IndexedDB

Схема имеет версию `DB_VERSION`; при повышении версии `onupgradeneeded` добавляет новые хранилища и отсутствующие индексы, сохраняя имеющиеся записи. JSON-резервная копия отдельно маркируется `schema_version` и проверяется до восстановления.

## Резервное копирование

Вверху нажмите «Резервная копия» либо в панели управления откройте раздел резервных копий. JSON включает версию схемы, дату экспорта и все хранилища IndexedDB. Восстановление валидирует формат и обязательно спрашивает подтверждение перед полной заменой текущих данных. Для переноса на другое устройство скачайте JSON на старом и импортируйте его на новом.

## Стартовые данные

При первом открытии в IndexedDB идемпотентно добавляются 56 тем ФИПИ 2027 из локальной базы оригинального проекта: 29 тем общей химии, 6 неорганической и 21 органической. Перенесены официальные коды, описания, источники, категории и родительские связи; добавлена одна подтверждённая запись исходного документа. В оригинальной базе связанные конспекты, задачи и тесты находились только у 70 повторяющихся тестовых тем `custom`, а не у импортированных тем ФИПИ, поэтому тестовые записи не перенесены. Для тем ФИПИ учебные материалы первоначально отсутствуют.

## Возможности

- Каталог с поиском, категорией и сортировкой; создание, редактирование и удаление тем с проверкой связанных записей.
- Теория: редактор разделов, блоки текста/списка/формул/определений/замечаний/таблиц, предпросмотр, оглавление и версии.
- Практика и тесты со ссылками на разделы конкретной версии конспекта, проверкой ответов и объяснениями.
- Три редактируемых ручных шаблона: `PROMPT_CONSPECT`, `PROMPT_TASKS`, `PROMPT_TEST`. Сайт лишь формирует и копирует текст; запросы к ИИ не выполняются.
- Черновики, публикация после ручной проверки, отклонение и история версий с восстановлением как новой версии.
- Импорт подготовленного JSON/CSV каталога ФИПИ с проверкой кодов, дубликатов, предпросмотром и подтверждением.
- Локальные заявки, настройки источников и полный JSON backup/restore.

## Ограничения

- Локальная IndexedDB — не общая база, не серверная авторизация и не защита от пользователя этого устройства.
- Браузерный импорт не скачивает и не разбирает официальный PDF/ZIP ФИПИ автоматически: для этого загрузите JSON/CSV с уже извлечёнными реальными данными. Приложение не имитирует успешное извлечение.
- Проверки JSON и связей не подтверждают химическую корректность. Перед публикацией вручную проверяйте формулы, реакции, вычисления и объяснения.
- Химические формулы показываются как обычный текст; сетевого рендерера формул нет.
- Данные IndexedDB относятся к профилю/браузеру. Очистка данных сайта удалит базу; делайте резервные копии.

## Структура

`index.html`, `css/` — оболочка и адаптивные стили; `js/` — IndexedDB, каталог, темы, редакторы, тесты, практика, промты, импорт, администрирование и backup; `data/initial-data.js` — выгрузка проверенных стартовых записей из оригинальной локальной SQLite.
